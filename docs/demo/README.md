# 演示页

用户在网页演示里调定的手绘风格和动效，写 UI 时照着移植（算法和数值以这里为准）：

- `boil-demo.html`：手绘墨线抖动、平涂色块错位、卡片、方框、勾号、悬浮按钮、静止画框、纸纤维/方格线（STYLE.md v0.5 定稿参数）。在线版 https://claude.ai/artifact/GtrK5kiX2qB9rrfPZiqzqq
- `m9-demo.html`：M9 的卡片沉下去再浮上来（平涂错位阴影）、标签切换和翻月滑动、日历正式标记（A 方案）。在线版 https://claude.ai/artifact/4e16LWF7wzjd6f4AgV9zzj

用浏览器直接打开即可（字体从 Google Fonts 加载，没网时会用系统楷体代替）。
