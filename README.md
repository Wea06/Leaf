# Leaf

自用的纯本地 Android 待办 App，目前完成 M6 导出 / 导入备份；M1～M6 均已真机验收通过。

## 本地运行

1. Android Studio 打开本仓库根目录，等待 Gradle 同步。
2. SDK 使用本地 local.properties 配置（不提交）；当前机器为 E:\Software\android\sdk。
3. Gradle JDK 选择 Android Studio 自带的 jbr。
4. 连接已开启 USB 调试的手机，选择 app 和手机设备，点击 Run。

构建与测试：` .\gradlew.bat assembleDebug testDebugUnitTest `。
当前共 81 项 JUnit4 单元测试，全部通过；保留 M2～M5 的 42 项，M6 新增 39 项。

构建版本沿用 Hello 测试工程：Gradle 9.6.0、AGP 9.5.0、
Kotlin 2.2.10、Compose BOM 2026.02.01，compileSdk / targetSdk 37。
minSdk 29，包名 com.leaftodo.app。

若本机 JDK 25 报 Unable to establish loopback connection，可仅在当前 PowerShell 会话设置：
`$env:JAVA_TOOL_OPTIONS = "-Djdk.net.unixdomain.tmpdir=$PWD"`，再运行构建。
该参数只调整构建进程的本机 socket 临时路径。

2. 准备无日期、有日期无时间、有时间、完成、划掉的事项，并加入多行内容。设置 → 导出备份 → 选择位置保存；核对“已导出 N 条”及文件管理中的 JSON 文件。再点导出并取消，应没有提示和数据变化。
3. 从备份导入 → 选择一个普通文本或其它非备份文件，确认提示不能导入，原事项仍在。
4. 导出后改几条事项，再选择刚导出的备份，检查确认框的导出时间、条数、覆盖说明；点取消，确认改动保留。重新选择并确认导入，数据应恢复到导出时。
5. 在文件管理的“下载/Leaf”中找到导入前自动另存的文件；导入这个文件，应恢复到第 4 步修改后的数据。核对提示中的文件名和条数。
6. 导出空数据的备份时应能正常保存和读取；导入空备份时确认框应明确说 Leaf 会变空；现在有事时仍先另存再清空。
7. 导出并确认文件可见后，将备份另拷一份，再卸载 App、重装当前 APK、导入备份；逐项核对标题、详细内容、日期、时间、状态、创建日期和日历标记，再新建一条确认正常。APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。
8. 确认操作过程没有权限申请；在确认框和提示框打开时转屏，状态应保留，导入完成后三页自动刷新。
