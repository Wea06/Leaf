# Leaf

自用的纯本地 Android 待办 App，目前完成 M3 新建 / 编辑页与今天列表；M1、M2、M3 均已真机验收通过。

## 本地运行

1. Android Studio 打开本仓库根目录，等待 Gradle 同步。
2. SDK 使用本地 local.properties 配置（不提交）；当前机器为 E:\Software\android\sdk。
3. Gradle JDK 选择 Android Studio 自带的 jbr。
4. 连接已开启 USB 调试的手机，选择 app 和手机设备，点击 Run。

构建与测试：` .\gradlew.bat assembleDebug testDebugUnitTest `。
当前共 15 项 JUnit4 单元测试，全部通过；包含 M2 原有 5 项和 M3 新增 10 项。

构建版本沿用 Hello 测试工程：Gradle 9.6.0、AGP 9.5.0、
Kotlin 2.2.10、Compose BOM 2026.02.01，compileSdk / targetSdk 37。
minSdk 29，包名 com.leaftodo.app。

若本机 JDK 25 报 Unable to establish loopback connection，可仅在当前 PowerShell 会话设置：
`$env:JAVA_TOOL_OPTIONS = "-Djdk.net.unixdomain.tmpdir=$PWD"`，再运行构建。
该参数只调整构建进程的本机 socket 临时路径。

手机验收：
1. Android Studio 选择 app 与手机，点击 Run 安装。
2. 清单页点 ＋，依次添加“买牛奶”“取快递”“给妈妈打电话”，确认顺序。
3. 点“买牛奶”的方框，确认橙底勾和灰字，移到“已结束”。
4. 长按“取快递”，选择“划掉（不做了）”，确认减号、灰字和删除线。
5. 从最近任务划掉 App 再打开，确认三条及状态保留。
6. 点“买牛奶”方框撤回；长按“取快递”选择“撤回成待办”。
7. 空白或全空格标题不能添加；键盘完成可以添加有效标题。
8. 今天页日期和星期正确；今天和日历的 ＋ 暂无操作。

M2 不包含编辑、日期时间选择、删除、今天列表、折叠、创建日期展示或手绘效果。


## M3 新建 / 编辑页与今天列表

状态：实现完成，构建和自动测试通过；用户于 2026-11-02 确认手机验收通过。未 push。

- 三页的 ＋ 打开整页新建，清单 / 日历默认无日期，今天默认当天；时间始终默认空。
- 清单和今天卡片支持点开编辑，卡片附带时间和详细内容第一行；方框和长按菜单保留。
- 标题、详细内容、日期、时间独立编辑；清空日期同时清空时间。仅改标题不动日期时间。
- 没有修改直接保存不写数据库；保存前读取最新记录，保留状态、创建时间、结束时间。
- 取消 / 返回有未保存修改时确认，删除需确认。输入内容、编辑状态在转屏后保留。
- 今天列表按时间、创建时间排序，已结束按结束时间倒序；App 每次回到前台刷新今天。
- 日期选择使用 UTC 转换；24 小时时间选择器默认停在 09:00，确认后才写入。
- 无新增依赖、权限或版本升级；数据库保持版本 1，schema 的 1.json 与 main 一致。

手机验收（已安装 M3 调试版，也可在 Android Studio 选择手机后 Run）：

1. 进入清单，点 ＋：整页显示“记一条”，无底部标签和 ＋，标题获得焦点并弹键盘；日期“无”，时间“先选日期”。空白标题不能保存。
2. 输入标题和两行详细内容，保存：回到清单，卡片显示详细内容第一行。标题键盘“下一项”跳到详细内容，详细内容回车换行。
3. 点卡片空白处编辑，选日期为今天，不选时间，保存：从清单消失，出现在今天页，没有时间。
4. 今天页点 ＋：日期默认今天，时间为空。输入另一标题，选 15:00 保存：排在无时间的事前，显示深橙色 15:00。
5. 打开这条，只改标题保存：日期仍是今天，时间仍为 15:00。再打开不作修改点保存，正常关闭。
6. 把日期改到另一日，时间应保留；清空日期，时间同时清空且不可选；重新加日期，时间仍为空。只清空时间时日期保留。
7. 日期选择器不选任何一天直接确定，日期保持空；任意选择一天，行内显示的日期与所选一致。时间选择器可选 24 小时，无紫蓝色。
8. 改动内容后按返回或取消：出现“不保存就离开？”，继续编辑保留内容，不保存则丢弃；无修改时直接退出。编辑页“删除这条”弹确认，取消保留、确认删除。
9. 点方框完成 / 撤回，长按划掉 / 撤回，今天和清单行为一致；已结束事项放在底部。
10. 编辑到一半转屏、切后台再回来：输入值保留；从最近任务划掉 App 再打开：已保存数据保留。后台放过夜后回来，今天的标题日期和列表跟随新一天。
11. 日历页点 ＋ 也能新建，日期为空；日历本身仍是占位页。
